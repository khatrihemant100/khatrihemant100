# 🧠 How I Approach Development

I am trying to move beyond:

> **"How do I write this code?"**

toward:

> **"What is the best way to solve this problem?"**

That means thinking about:

**1. Problem**  
What problem are we actually solving?

**2. Users**  
Who will use the product and why?

**3. Architecture**  
How should the system be structured?

**4. Data**  
What information needs to be stored, retrieved, and protected?

**5. Experience**  
Can the user understand and use the product easily?

**6. Maintainability**  
Will another developer understand and extend the code?

**7. Scalability**  
What happens if the number of users grows?

**8. Security**  
What should never be trusted or exposed?

This mindset is something I am actively developing as I move toward professional software engineering.
